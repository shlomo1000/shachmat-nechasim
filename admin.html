חיבור לאתר

פעם אחת בלבד. הפרטים נשמרים רק בדפדפן שלך, והחיבור מאפשר לשמור שינויים ישירות לאתר.

איך יוצרים קוד גישה?
  1. בגיטהאב: Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. Repository access: Only select repositories, ובחר את ריפו האתר.
  3. Permissions ← Repository permissions ← Contents: Read and write.
  4. העתק את הקוד והדבק כאן. אל תשתף אותו עם אף אחד.
